# Pacote Axial: execução local

Demo funcional: `/demos/agendamento.html`, dados fictícios e armazenamento apenas no navegador. Não há CRM, coleta de contatos, envio ou estabelecimento real.

Renderização: `npm ci`, depois `npm run render` e `npm run cover` neste diretório. Coloque a captura validada da demo em `public/demo-ui.png`. O vídeo tem 12 segundos, 1080×1920, sem voz ou ativos pagos. Não há render na nuvem. O projeto é separado do build obrigatório da Central.
